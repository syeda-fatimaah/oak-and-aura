# Gujrat Furniture Gulyana

A premium furniture e-commerce website for **Gujrat Furniture Gulyana** — located on Naseera Road, Gulyana, Kharian. Built with React + TypeScript + Vite.

## 🛋️ About

Gujrat Furniture Gulyana is a trusted furniture business owned by **Abdul Rahman**, serving the Kharian community with high-quality furniture at affordable prices. This website showcases their complete range of sofas, bedroom sets, dressing tables, and bridal furniture.

## ✨ Features

- **Product Shop** — Browse sofas, beds, dressing tables and bridal furniture
- **Collections** — Curated room collections with filtering
- **Gallery / Lookbook** — Visual gallery with lightbox view
- **Quick View** — View product details without leaving the shop
- **Wishlist & Cart** — Save favourites and manage orders
- **WhatsApp Integration** — Direct contact via WhatsApp
- **Dark Mode** — Toggle between light and dark themes
- **Fully Responsive** — Works on mobile, tablet and desktop
- **Blog** — Furniture tips and guides

## 🛠️ Tech Stack

- **React 18** + **TypeScript**
- **Vite** (build tool)
- **Framer Motion** (animations)
- **React Router** (navigation)
- **Lucide React** (icons)
- **Vanilla CSS** (styling)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
